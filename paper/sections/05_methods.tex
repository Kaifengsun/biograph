\section{Methods}
\label{sec:methods}

\subsection{Bottom-up source-chunk retrieval}

The bottom-up path searches source-linked representations. Youtu-Embedding supplies the frozen dense vectors; generated summaries and questions map back to source chunks before deduplication. BM25 indexes parent context, heading, and the first 2,000 chunk characters with $k_1=1.2$ and $b=0.75$ \cite{robertson2009bm25}. Both methods rank the same 2,478 identifiers.

\subsection{Top-down document routing}

Candidate ranks vote for documents through reciprocal-rank contributions. The two leading documents define a restricted chunk search, and returned chunks retain their root-to-section path. Generated profiles choose where to search, never what to cite. Unlike learned clustering trees, this route preserves the source document hierarchy \cite{sarthi2024raptor}.

\subsection{Bounded graph traversal}

Deterministic breadth-first traversal has depth four and expands at most 800 states. Structured paths preserve edge direction, node properties, and provenance. A separate experimental route uses graph-reachable documents to constrain text retrieval. Structured records remain outside text metrics.

\subsection{Relation-aware evidence-chain ranking}

A feedback-driven supplementary experiment ranks connected, possibly branching graph chains of one to five canonical directed triples. Candidate generation uses a fixed 12-relation supply-and-regulatory projection, question-matched entity anchors, and identical candidates for all conditions. B0 orders chains only by length and signature. M0 adds question--node token overlap, edge provenance coverage, and a length penalty. R1 additionally scores coverage and precision of explicit relation phrases and anchor-relative canonical orientation. Cue-off and direction-off remove the corresponding R1 components. Exact feature weights, aliases, caps, graph hashes, and deterministic tie-breaking were frozen in a machine-readable lock before evaluation.

\subsection{Fusion and adaptive variants}

Bottom-up, top-down, and graph-constrained rankings use reciprocal-rank fusion. For source chunk $c$,
\begin{equation}
s_{\mathrm{RRF}}(c)=\sum_{r\in\{b,t,g\}}\frac{w_r}{k_0+\operatorname{rank}_r(c)},
\end{equation}
where $k_0=60$, $w_b=w_t=1$, and $w_g=0.5$ only for a direct graph record, explicit document anchor, or text-graph agreement. Bounded metadata gains handle explicit document and table intent.

\subsection{BM25-anchored selective reranking}

The selective reranker returns BM25 unchanged unless the query explicitly requests a table or two distinct table chunks occur in the combined top-five lists. When enabled, it assigns
\begin{equation}
s(c)=\frac{1}{60+r_{\mathrm{BM25}}(c)}+\frac{1}{60+r_{\mathrm{dense}}(c)}+\frac{0.25I_{\mathrm{table}}(c)}{61}.
\end{equation}
Missing ranks contribute zero. The gate depth, support threshold, and table weight were selected on 90 observed queries and frozen.

Two later locked extensions test semantic reordering without fine-tuning. Qwen3-Reranker-0.6B scores BM25's fixed top 50 with its official yes/no relevance formulation, BF16 precision, and 1,024-token input \cite{zhang2025qwen3embedding}. MedCPT uses its official query encoder (64 tokens) and article encoder (512 tokens) with unnormalized dot product over all 2,478 chunks; its cross-encoder separately reranks the same BM25 top 50 at 512 tokens \cite{jin2023medcpt}. Exact model revisions, files, payloads, code, and seeds were hashed before MedCPT scores were observed. Both extensions are feedback-motivated supplementary analyses because the 58 questions were already observed.
