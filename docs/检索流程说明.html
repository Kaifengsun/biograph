化工安全知识图谱 — 检索流程

三阶段图谱检索 · S1 每次必经 · S1.5 / S2 按条件触发 · S3 关系扩展（建设中）

S1

关键词 + 语义检索

触发条件：每次请求必经

jieba 分词 + 实体抽取
从问题中提取关键词、化学品名、标准号
关键词匹配
检索 Section.content / title / keywords / summary / entities
向量语义搜索
Youtu-Embedding 生成查询向量，余弦相似度召回语义相近 Section
QAPair 向量搜索
召回历史问答对，补充相关知识
S1.5

Bottom-Up 补全

触发条件：检索到的 Section 内容 < 80 字时

向上溯源
拉取该 Section 所属的父标准（Standard 节点）
兄弟章节补充
拉取同级相邻章节，扩充上下文窗口
S2

Top-Down 展开

触发条件：S1 在同一标准下命中 ≥ 2 个 Section（标准聚类）

标准聚类
统计各标准命中 chunk 数，识别主导标准（_cluster_standards）
自顶向下扩展
从主导标准根节点沿 HAS_SECTION 关系向下，补充目录结构章节
S3

图谱游走

建设中

触发条件：问题涉及多个化学品 / 因果关系时（当前化学品间关系较少，暂未充分激活）

种子节点激活
以化学品节点为起点，沿 RELATED_TO / HAS_SECTION 关系追踪路径
LLM 路径过滤
过滤与问题无关的路径，保留高置信度关系链（_llm_navigate_paths）
RRF

融合排序

Reciprocal Rank Fusion
合并 S1 + S2 结果，消除重复，按综合相关性重排，取 Top-K 送入 LLM

LLM 回答策略

有检索结果
  • ① 上下文直接相关 → 引用原文回答，末尾注明标准编号和章节
  • ② 上下文部分相关 → 引用相关部分，说明未覆盖的方面
  • ③ 上下文主题不同 → 说明检索内容，指出应查阅的标准系列
严禁引用检索上下文以外的标准编号
无检索结果
  • 强制输出声明：【知识库未检索到相关内容，以下基于通用知识回答，仅供参考】
  • 基于化工安全领域通用知识给出参考回答
  • 末尾建议可能相关的标准系列（GB / AQ / HG / SY）
不得编造不存在的标准编号
